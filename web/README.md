# gRPC Client (Web application)

Browser client for `demo.news.v1.NewsService` ([proto](../proto/demo/news/v1/news_service.proto)):

- UI: [Svelte 5](https://svelte.dev/) built with [Vite](https://vite.dev/), styled with [Pico CSS](https://picocss.com/)
- gRPC client: [Connect-ES](https://connectrpc.com/docs/web/getting-started) with its grpc-web transport
- Server: [Hono](https://hono.dev/) serves the built app and proxies `/grpc` to the gRPC server with
  [grpc-web-middleware](https://github.com/fb64/grpc-web-middleware). Browsers cannot speak gRPC (HTTP/2 trailers),
  so the proxy translates grpc-web to gRPC.

```
browser ──grpc-web──> Hono (:3000) ── grpc-web-middleware ──gRPC──> news server (:6565)
```

The page lists the news by topic, follows new ones live with the `Subscribe` stream (with a "Breaking news" banner),
and publishes news with `PostNews`.

## Run

Start the server first (`mise run server`, see the [server project](../backends/kotlin-graal)), then from the repository root:

| Command                | What it does |
|------------------------|--------------|
| `mise run web`         | Development, with hot reload, on http://localhost:5173. The Vite dev server proxies `/grpc` itself (`vite.config.ts`) |
| `mise run web:start`   | Production build served by the Hono server (`server/index.ts`) on http://localhost:3000 |
| `mise run web:check`   | Type-check with `svelte-check` |
| `mise run web:image`   | Build the `news-web` container image |

Both servers read `GRPC_TARGET` (default `http://localhost:6565`); the Hono server also reads `PORT` (default `3000`).

```sh
podman run --rm -p 3000:3000 -e GRPC_TARGET=http://host.containers.internal:6565 news-web   # or docker
```

## Code layout

| Path                   | Content |
|------------------------|---------|
| `src/lib/client.ts`    | The Connect-ES client (one line of transport configuration) |
| `src/lib/feed.svelte.ts` | `GetNews` + `Subscribe` + `PostNews`, as Svelte reactive state |
| `src/App.svelte`, `src/lib/PostForm.svelte` | The UI |
| `server/index.ts`      | Production server (run directly by Node.js, no build step) |
| `src/gen`              | Generated by `mise run generate` (`buf generate`, see [buf.gen.yaml](../buf.gen.yaml)), committed. Do not edit |
